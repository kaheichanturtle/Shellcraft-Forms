How to Get Your Google Script URL

Follow these steps to create a smart backend that will collect your form responses in a Google Sheet.

  1. Go to sheets.google.com/create to create a new spreadsheet. Name it whatever you like.
  2. Important first step: Click on cell A1 (the top-left cell) and type at least one header name, like "Timestamp". This helps the script work correctly from the very first submission.
  3. In the menu, go to Extensions → Apps Script.
  4. Delete any placeholder code and paste the following script. This new script automatically handles all your other headers for you. function doPost(e) { try { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0]; var newRow = new Array(headers.length).fill(''); var headerMap = {}; headers.forEach(function(header, i) { headerMap[header] = i; }); for (var key in e.parameter) { if (headerMap.hasOwnProperty(key)) { newRow[headerMap[key]] = e.parameter[key]; } else { var newHeaderIndex = headers.length; sheet.getRange(1, newHeaderIndex + 1).setValue(key); headers.push(key); headerMap[key] = newHeaderIndex; while(newRow.length < headers.length) { newRow.push(''); } newRow[newHeaderIndex] = e.parameter[key]; } } sheet.appendRow(newRow); return ContentService.createTextOutput(JSON.stringify({ "result": "success" })).setMimeType(ContentService.MimeType.JSON); } catch (error) { return ContentService.createTextOutput(JSON.stringify({ "result": "error", "error": error.toString() })).setMimeType(ContentService.MimeType.JSON); } }
  5. Save the project (floppy disk icon).
  6. Click the blue Deploy button → New deployment.
  7. Click the gear icon (⚙️) and choose Web app.
  8. Configure it as follows: Execute as: Me, Who has access: Anyone.
  9. Click Deploy. Authorize the script when prompted (you may need to click "Advanced" and "Go to... (unsafe)").
  10. After deploying, copy the Web app URL. That's what you need!
